# STUKACH — Справочник чекеров

Аддон проверяет ассеты по pipeline-регламенту кино-производства.
Каждый чек можно включить/выключить независимо; результат отображается цветовым индикатором в N-панели и оверлеем прямо на меше.

---

## Уровни критичности

| Уровень | Значение | Влияние на статус ассета |
|---|---|---|
| 🔴 **BLOCKER** | Ассет нельзя сдавать в таком виде. Проблема гарантированно сломает рендер, экспорт, симуляцию или downstream-пайплайн. Требует исправления до передачи. | Ассет получает статус **FAIL** |
| 🟡 **WARNING** | Проблема реальная, но не всегда катастрофическая. Артист должен осознанно принять решение — исправить или обосновать исключение. | Ассет получает статус **REVIEW** |
| 🔵 **INFO** | Информация для ревью. Не является ошибкой — подсвечивает места, требующие осознанного решения артиста. Не влияет на статус сдачи. | Статус ассета **не меняется** |

## Блок TOPOLOGY

Проверяет корректность полигональной сетки — ошибки ломающие риггинг, симуляцию, рендер или экспорт.

| Чек | Критичность | Что ищет | Зачем нужен |
|---|---|---|---|
| **Non Manifold** | 🔴 BLOCKER | Рёбра с ≠ 2 смежными гранями (T-стыки, рёбра без граней) | Ломает булевы операции, симуляции ткани/жидкости, расчёт нормалей и экспорт в форматы требующие замкнутого объёма (FBX, USD) |
| **Boundary Edges** | 🔵 INFO | Открытые рёбра — ровно одна смежная грань | Незакрытые края могут быть намеренными (скрытые грани для UV, вырезы). Подсвечивает для ревью |
| **Isolated Verts** | 🟡 WARNING | Вершины не связанные ни с одним ребром | Мусорная геометрия — засоряет vertex group'ы и UV, не видна в рендере |
| **Duplicate Verts** | 🔴 BLOCKER | Вершины в одной точке пространства (порог 0,01 мм) | Дубли нарушают расчёт нормалей, шейдинг, симуляции. Возникают после булевых операций, knife, случайного Ctrl+D |
| **Face Aspect Ratio** | 🔵 INFO | Квады с соотношением сторон выше порога (по умолчанию 6:1) | Вытянутые квады дают артефакты при subdivide и скиннинге. Подсвечивает для осознанного решения |
| **Triangles** | 🔵 INFO | Треугольные грани | Мидполи воркфлоу допускает триангуляцию — чек подсвечивает треугольники для ревью артистом. Критично только в deform-зонах и под subdivide |
| **Ngons** | 🟡 WARNING | Грани с 5+ рёбрами | Непредсказуемо триангулируются рендером и экспортёром; артефакты нормалей на жёстких поверхностях |
| **Poles** | 🔵 INFO | Вершины с нестандартным числом рёбер (3, 5, >5 или 0) | Топологическое наблюдение — полюса влияют на subdivide и скиннинг, но часто намеренны |
| **Zero Area** | 🔴 BLOCKER | Грани с площадью < 1e-10 | Вырожденные грани дают NaN в расчётах нормалей, нарушают UV-развёртку. Возникают после boolean, Knife вдоль ребра, Merge |
| **Flipped Normals** | 🟡 WARNING | Грани с нормалью направленной внутрь | Невидимые грани с backface culling, артефакты в real-time движках, неправильное SSS. Может быть намеренным (sky dome, double-sided geo) |
| **Z-Fighting** | 🔴 BLOCKER | Копланарные грани перекрывающие друг друга | Мерцание в рендере и real-time. Артефакт boolean или случайного Ctrl+D |
| **Invalid Normals** | 🟡 WARNING | Кастомные split-нормали нулевой длины или против геометрической нормали | Ломают шейдинг и экспорт. Возникают после импорта FBX или Data Transfer |

## Блок TRANSFORMS

Проверяет трансформации объекта и обязательные модификаторы. Неприменённые трансформы — одна из самых частых причин проблем при передаче ассета.

| Чек | Критичность | Что ищет | Зачем нужен |
|---|---|---|---|
| **Non Applied Transform** | 🔴 BLOCKER | Ненулевой Rotation (rotation_euler ≠ 0) | Неприменённый поворот меняет направления нормалей при экспорте, ломает физику и ориентацию костей |
| **Scale** | 🔴 BLOCKER | Scale ≠ 1.0 по любой оси (допуск 0,001) | Ненормализованный scale искажает симуляции, деформации скелета и расчёт texel density |
| **Origin At Zero** | 🔵 INFO | Pivot объекта не в мировом нуле (0, 0, 0) | Может быть намеренным (петля, шарнир, объект с конкретным pivot'ом). Подсвечивает для ревью |
| **Modifier Stack** | 🟡 WARNING | Неприменённые модификаторы (кроме Armature) | Случайный Subdivision, Bevel или Mirror меняет финальную геометрию при экспорте |
| **Smooth by Angle** | 🟡 WARNING | Наличие модификатора Smooth by Angle / Auto Smooth с углом 180° | По регламенту шейдинг управляется через этот модификатор; угол 180° + sharp edges |

## Блок SYMMETRY

Проверяет зеркальную симметрию меша. Используется для персонажей, транспорта и любых симметричных объектов.

| Чек | Критичность | Что ищет | Зачем нужен |
|---|---|---|---|
| **Symmetry X** | 🔵 INFO | Вершины без зеркальной пары по оси X (KD-Tree) | Нарушенная симметрия ломает mirror-риг, blend shapes, morph targets. Включается осознанно для симметричных объектов |
| **Symmetry Y** | 🔵 INFO | Вершины без зеркальной пары по оси Y | Аналогично — для объектов с симметрией по Y |
| **Symmetry Z** | 🔵 INFO | Вершины без зеркальной пары по оси Z | Аналогично — для объектов с симметрией по Z |

## Блок UV

Проверяет UV-развёртку по всем критериям pipeline-регламента. UV-ошибки напрямую влияют на качество текстурирования и UDIM-пайплайн.

| Чек | Критичность | Что ищет | Зачем нужен |
|---|---|---|---|
| **UV Single Set** | 🟡 WARNING | Количество UV-сетов ≠ 1 | Несколько сетов — признак незавершённой работы или конфликта пайплайна |
| **UV Overlap** | 🔴 BLOCKER | Перекрывающиеся UV-острова разных материальных групп | Оверлап = одинаковые текселы для разных полигонов: невозможно запечь уникальные текстуры |
| **UV Micro Shell** | 🟡 WARNING | UV-острова с площадью ниже порога (≈ 6×6 px при 2048) | Острова слишком маленькие для текстурирования; занимают место в атласе, дают размытые текселы |
| **UV Texel Density** | 🔵 INFO | Отклонение texel density от целевого значения (px/cm) | Инструмент ревью TD — показывает реальное значение. Становится активным контролем только при заданном target TD |
| **UV Stretch** | 🟡 WARNING | Грани где угол UV-пространства сильно отличается от 3D-угла | Стрейч = искажение текстуры: заметен на паттернах и деталях normal map |
| **UV Padding** | 🔵 INFO | Расстояние между UV-шеллами < минимума (16 px) или до границы тайла < минимума (8 px) | Недостаточный padding даёт bleeding при mip-mapping. Информационно — padding может намеренно варьироваться |
| **UV UDIM Bounds** | 🔴 BLOCKER | UV-острова выходящие за границы UDIM-тайла | Остров в двух тайлах = невозможно назначить правильную UDIM-текстуру; рендер получает артефакты на шве |
| **Mat per UDIM** | 🔴 BLOCKER | Несколько материальных групп на одном UDIM-тайле | Ломает UDIM-адресацию в рендерере и автоматизированный пайплайн текстурирования |

## Блок NAMING

Проверяет соответствие имён объектов, коллекций и материалов naming-политике. Правильные имена — обязательное условие для автоматизированного пайплайна.

| Чек | Критичность | Что ищет | Зачем нужен |
|---|---|---|---|
| **Object Naming** | 🟡 WARNING | Дефолтные имена (Cube, pCube1), Blender-нумерация (.001), спецсимволы, заглавные буквы, несоответствие префиксам/суффиксам | Некорректные имена ломают скрипты ассет-менеджера, pipeline-инструменты и все системы с exact name matching |
| **Collection Naming** | 🟡 WARNING | Те же правила для коллекций | Нарушенный нейминг ломает иерархию, LOD-системы и shot assembly |
| **Mat Numbering** | 🟡 WARNING | Имена материалов с Blender-нумерацией (.001, .002 ...) | Нумерованные материалы — копия вместо оригинального material asset; ломает материальную библиотеку |

---

## Блок MATERIALS

Проверяет корректность назначения материалов и состояние текстур.

| Чек | Критичность | Что ищет | Зачем нужен |
|---|---|---|---|
| **Mat Suffix** | 🟡 WARNING | Имена материалов без суффикса `_mat` | Единый суффикс позволяет однозначно отличать материалы от мешей и коллекций в скриптах |
| **Mat Assignment** | 🔴 BLOCKER | Пустые слоты материалов (слот есть, материала нет) | Объект с пустым слотом рендерится без материала — чёрная геометрия в продакшн-рендере |
| **Missing Textures** | 🔴 BLOCKER | Текстурные ноды (Image Texture) с отсутствующим файлом на диске | Пропавший файл = розовый / чёрный рендер |

---

## Блок CLEANUP

Проверяет наличие мусорных данных, которые не влияют на рендер, но замедляют файл и мешают чистому пайплайну.

| Чек | Критичность | Что ищет | Зачем нужен |
|---|---|---|---|
| **Unused Data** | 🟡 WARNING | Пустые vertex group'ы, shape key'и только с basis, UV-сеты без данных, материальные слоты без полигонов | Мусорные данные раздувают файл, мешают авто-риггерам и скриптам |

---

## Scene Units (уровень сцены)

| Чек | Критичность | Что ищет | Зачем нужен |
|---|---|---|---|
| **Scene Units** | 🔴 BLOCKER | System ≠ Metric, Length Unit ≠ Meters, Scale Length ≠ 1.0 | Неверные единицы ломают формулу texel density, физику, FBX-экспорт (масштаб ×100) |
